# 溪禾手记 · 风从田野来

面向学生的乡村探究叙事游戏。你以实践小队员的身份来到溪禾村，和周伯种下一季青菜，调查两畦不同的长势，亲手布置小试验，并把这一季带上秋日饭桌。

这是 v0.3 可玩原型。它已实现完整故事与研究循环；实时画面仍是程序化风格化 3D，并未达到《原神》级别的角色、美术或演出质量。

## 本机运行

已包含打包好的 dist，无需先安装依赖。安装 Node.js 18 或以上后，在项目目录运行：

```sh
node server.cjs
```

打开 http://127.0.0.1:4177/ 。Windows 也可以双击“启动游戏.cmd”。若端口被占用，可设置 PORT；服务仅监听本机。不要直接双击 HTML，浏览器对本地文件的限制可能影响运行。

修改源码后：

```sh
npm install
npm run build
npm test
npm run check
```

唯一构建依赖为 esbuild，版本固定。浏览器运行不调用外部 AI、不需要账号或 API 密钥。无需付费服务。

## 这一版的实际玩法

- 第三人称行走、环视、近距离互动、可选地图路线辅助。
- 扶木签、与周伯相识、共同种植、发现长势差异。
- 自由寻找溪岸、田埂、照料记录等线索，没有强制发现顺序。
- 选择表层或根部取样，保留日期、深度、地点和三点测量。
- 选择水壶、稻草或少量肥料；给两组作物留下木签，连续复查三次。
- 不同补水量、覆盖、肥料、天气和照料会改变同一个教学模型的水分与生长状态。
- 分别安排两畦照料，雨后再作决定，收获后与周伯、周宁围坐饭桌。
- 本机自动保存、继续游玩、重新开始和下载个人手记。

WASD / 方向键移动，拖动场景环视，E 互动，Q 小禾，J 手记，M 地图。触屏提供摇杆；真实手机性能尚未验收。

## 小禾如何参与研究

小禾是明确标注的**本地规则模拟伙伴**，未连接真实语言模型。学生可以自己提问，决定是否附上记录，比较解释并检验建议；不必先和小禾对话才能继续游戏。小禾只能读取显式附上的测量、已发现线索和试验结果，不会读取未发现事实或未来天气。它会指出条件不同、证据不足和因果不确定性；最终行动由玩家决定。

规则模拟只覆盖本章有限表达，并不具备通用聊天理解能力。数据只在本机浏览器保存；目前没有云同步或教师后台。

## 质量边界与下一步

教学数值用于演示变量之间的关系，未经实地农艺校准，不用于真实种植决策。收获数量和用水量都是模型输出。

开场采用原创生成插画，并明确注明“进入后为可探索 3D 场景”；插画不是实时游戏截图。场景、人物和动作主要由代码生成，尚无专业角色骨骼、表情、配音或完整音乐制作。

下一轮优先邀请学生观察试玩，记录他们在哪里主动提出问题、哪里只追提示；同时制作正式角色资产、镜头演出和环境细节。自由选作物、自由提研究问题、真实 AI 接入和多人协作均未完成。

实际测试证据见“测试记录.md”。
