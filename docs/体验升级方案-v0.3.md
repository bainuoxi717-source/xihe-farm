# 溪禾手记：体验升级方案 v0.3

2026-10-27 原方案；2026-10-28 更新实现状态。以下保留原设计目标，实际交付范围以 README 与测试记录为准。

已完成：自由线索、深度取样、可选 AI、三种试验、连续教学模型、两畦照料、雨后决策、饭桌结尾、手记与存档、基础角色动作和植被升级。部分完成：实时美术与角色演出、研究交互自然度。未完成：专业角色资产/配音/表情、玩家自由选择作物与问题、真实 AI、学生与真实移动设备验收。目标 15–20 分钟是设计预期，尚未做学生群体时长统计。

建议将下一版定义为：一段 15–20 分钟、有明确美术品质和角色演出的乡村探究故事。第一个制作单元是可独立试玩的 5 分钟开场。先以小学高年级至初中学生开展探索性试玩；低龄玩家提供更少文字、更多动作示范和可主动开启的引导。

玩家应带走三个感受：我想知道这片田发生了什么；我在乎周伯的这一季；我的调查真的改变了接下来发生的事。

## 当前版本的具体差距

| 当前实现 | 对体验的影响 | 升级方向 |
|---|---|---|
| `story.js` 用单一阶段安排每一步；`goal()` 常指定唯一目标 | 玩家很容易只追任务标记，自己的发现没有改变路径 | 保留关键剧情节点，调查阶段改为可交叉发现的线索网络 |
| `openRecord()` 直接给出两侧预设读数 | 取样动作缺乏选择，数据像被系统发放 | 玩家选择位置和时刻，读数带位置、深度、时间与观察对象 |
| `openTrial()` 展示固定数组，等待通过三次长椅推进 | 等待主要是重复点击，作物变化缺少共同经历 | 关键日切片配合照料动作、天气预兆、角色小事件和前后对照 |
| `result()` 用照料与雨后选项映射收成 | 收成更像选项得分，玩家难以从世界变化解释结果 | 建立小规模、可复现的教学模拟，使操作、土壤状态、天气与生长连续关联 |
| NPC 位置固定，角色信息集中在对话框 | 人物主要承担任务入口，关系靠台词宣布 | 日常动作、同行片段、玩家行为记忆、共同完成的场景 |
| 场景主要由程序化几何体组成 | 缺少独特轮廓、材质层次、生活痕迹和有表情的人物 | 独立角色资产、经过设计的建筑与植被、地形构图、统一光色和动画 |

## 对标标准与使用边界

《原神》沉玉谷的官方介绍把聚落生产、地方传说、山谷水系和画面气氛放在同一区域中，并介绍了服务于山水画观感的雾与山体色彩处理。我们借鉴“场景的形态、生活与故事相互支持”的方法。溪禾村的水沟、梯田、晒场和饭桌都应有可理解的用途。[HoYoverse：沉玉谷设计与视觉技术](https://blog.playstation.com/2024/01/19/genshin-impact-version-4-4-brings-new-friends-and-visual-enhancements-jan-31/)

层岩巨渊的官方介绍将勘探团队、区域历史、探索工具和剧情推进放在一起。对本项目的启发是：研究工具应改变玩家能观察什么、能做什么，并自然连接人物故事。以下具体玩法和验收数字均是本项目的设计建议，不是《原神》的官方设计规范。[HoYoverse：层岩巨渊探索介绍](https://blog.playstation.com/2022/03/18/genshin-impact-version-2-6-lets-dig-into-the-chasm/)

采用原创中国乡村美术、角色和音乐。对标重点为镜头构图、角色存在感、环境反馈、动作连贯和探索吸引力。本阶段聚焦一个村庄、两片主要菜畦和一季故事。

## 一段可以实际制作的故事

章节沿用《风从田野来》，围绕周伯为秋日饭桌准备的一篮青菜展开。女儿即将回村，让承诺有具体的人和时间。周伯擅长看土、照料，也对新修田埂带来的变化不确定；他能教玩家，也愿意一起修正判断。

| 目标时段 | 玩家实际经历 | 研究与情感的作用 |
|---|---|---|
| 0–2 分钟：走进村子 | 石桥转弯后看见梯田和晒场。周伯正在扶一块倒下的木签。玩家可以帮忙、先看水车或走近菜地 | 通过小事认识人物，第一次偏离主路也有回应 |
| 2–4 分钟：一起种下去 | 两人分种一畦，周伯示范覆土。工具棚里有一只旧菜篮，提到女儿回来的日子 | 共同劳动建立约定；短蒙太奇表现连续照料与生长 |
| 4–7 分钟：自己发现异常 | 同一视角中两侧叶片与土面出现差异。周伯蹲在西畦，没有立即宣布原因。玩家可沿田边、溪岸或工具棚找线索 | “我发现了问题”成为推进动力 |
| 7–11 分钟：把想法种进田里 | 查看叶片、测量两处、询问周伯、向小禾出示记录。自己圈两组相近植株、插签、选择一项处理 | 比较解释，亲手建立可验证的试验 |
| 11–15 分钟：条件变了 | 等待用几个有内容的关键日呈现。补水组出现变化，天空转暗。周伯搬起晒场的东西，玩家听见第一滴雨 | 让原计划接受新证据检验；研究与村庄生活同时发生 |
| 15–20 分钟：这一季留下什么 | 玩家复查田地、调整照料、参与收菜。女儿在饭桌旁出现或通过短演出完成归来的承诺。周伯留着两人写过的木签 | 行动在作物和人物关系中得到回应；结尾手记展示自己走过的路径 |

时间为节奏目标，允许闲逛、重测和跳过已看过的演出。先用试玩调整实际长度。

开场台词方向：“这块木签又被风吹倒了。帮我扶一下？字朝着路——等她回来，一眼就能看见。”人物先关心正在发生的事，解释教学知识时只说眼前需要的部分。

## 探索：三条路径，同一片会变化的田

空间采用紧凑的环形连接：村口石桥 → 菜畦 → 工具棚 → 晒场 → 溪岸 → 返回菜畦。菜畦是反复经过的视觉中心。桥、棚顶、树冠、流水声形成辨认方向的线索。

| 路径 | 可发现的内容 | 对后续行动的价值 |
|---|---|---|
| 田边近路 | 叶片状态、两侧土面差异、木签的旧日期 | 提出可测量的问题，建立当前基线 |
| 溪岸小路 | 新旧土层交界、排水路径、雨后留下的痕迹 | 补充土壤与水分流动的解释；雨后值得再来 |
| 工具棚与晒场 | 旧照料记录、可用工具、周伯的生活物件 | 对照过去条件，得知人物牵挂，选择验证方法 |

任何一条线索都不直接宣布最终原因。同一问题允许从不同线索进入；关键线索可重复查看。玩家可以先询问、先测量或先做小范围尝试，研究记录呈现各自代价和不确定性。

平时任务只保留意图，例如“陪周伯把这一季种好”。接近物件才出现短互动提示。求助提供三级：人物自然提示 → 标出大致区域 → 主动开启路线辅助。自动前往保留为可选择的辅助方式。

每次主动偏离路线至少获得一项有意义的回应：人物往事、可用的比较证据、一个能改变照料方式的小工具，或回程更方便的通路。可拍照留念，但风景收集不作为通关门槛。

## 研究：让玩家的操作产生因果

下一版优先打磨四个动作：蹲下看叶、取样测量、圈定与标记、控制补水。动作要有手部接触、工具声音、土面变化和短反馈。简单点按与按住两种操作均可，不设置要求精细手速的失败惩罚。

试验允许玩家在相近的小块田上保留对照。若同时改变多个条件，游戏仍记录并推进；结果出现后，小禾或周伯帮助指出“这次还分不清是哪一项起作用”，玩家可以追加比较。不要把实验规范变成另一套答题解锁条件。

模拟采用少量可解释的变量：土壤保水与排水特征、当前水分、天气输入、玩家处理、随时间累积的生长状态。每次测量记录位置、时间、深度与方法；区分真实模拟状态和仪器显示精度。首轮使用固定情境和可复现的小幅变化，便于调试与教学解释。

叶片、土面、水洼和仪器读数由同一状态驱动。补水先改变土壤状态，生长变化在后续关键日呈现。收成由这一季的状态变化产生。所有参数仍标注为教学模型，不提供真实农艺阈值或预测承诺。

反馈分别展示作物恢复、资源使用和还没验证的问题。人物关系通过动作和对白体现。尝试失败会留下记录、调整机会和不同结尾内容；饭桌上的邀请不会因为产量低而被取消。

## AI：随身探究工具，有用且可以被质疑

将“小禾”放在随身设备中。玩家对着某株青菜或一份记录发问，可以主动附上照片式观察记录与测量数据。默认不暂停整个世界，界面只占一侧；长文本进入手记。

| 玩家状态 | 小禾应提供什么 | 玩家仍掌握什么 |
|---|---|---|
| 只有“看起来蔫了”的观察 | 澄清地点和时间，提出还需要比较的对象 | 去哪里、观察什么 |
| 有两处记录 | 依据已附证据列出可竞争的解释，并指出缺口 | 先验证哪一种解释 |
| 想开始试验 | 询问希望只改变什么、保留哪组作为比较 | 试验对象、处理方式与投入 |
| 结果与预期不同 | 比较原预测与新证据，提出复查或修改方案 | 是否继续、改变或暂缓 |
| 想照搬建议 | 简述依据和风险，提醒小范围试验；避免反复说教 | 最终行动与记录理由 |

示例：玩家问“西边是不是缺水？”小禾回答：“你记录的两处水分有差异。不过这两次是不是同一时间测的？你可以补一组同时间记录，也可以先在西畦留两小组，看看只改变补水会发生什么。”系统只在确实缺少时间信息时提出这个追问。

小禾只使用玩家主动提供的可见信息，不读取隐藏成因、未来天气或结局。即使仍是本地模拟，也采用结构化的“证据—假设—验证—更新”状态，诚实标注能力范围。遇到不支持的问题，说明范围，并提供与当前记录相关的入口。

主线安排一次自然的 AI 求助机会，展示它整理比较证据的价值。玩家可以拒绝建议、转问周伯或先做试验，之后带结果回来。玩家拥有决定权，AI 不替玩家自动操作田地。

## 画面与演出：建立可验收的样板

美术方向为“雨后中国乡村，清透光线与绘画质感”。以溪水青、稻草金、瓦灰和暖木色建立层次；人物与互动对象在繁茂环境中仍能辨认。保留真实农业逻辑，夸张用于轮廓、光色和动作可读性。

| 必做样板 | 可验收内容 |
|---|---|
| 村口石桥远景 | 前景遮挡、清晰通路、中景人物与菜畦、远景山体；转弯后形成一次视野展开 |
| 田边双人近景 | 正式比例与轮廓的学生、周伯模型；眼神、呼吸、握持工具、蹲下、起身、交接动作；脚部接地 |
| 雨后菜畦近景 | 湿润土面、水洼、叶片变化、滴水与雨后声音；玩家行动前后的差异清楚可见 |
| 秋日饭桌收束 | 木签或菜篮再次出现，人物有回应动作，镜头停留在共同经历留下的物件 |

角色、建筑、工具和植被采用独立美术资产制作流程。先做能近距离看的两位主要角色、一个有生活痕迹的院落和一段田边路径；再扩展剩余场景。统一材质与光照风格，避免把不同风格素材直接拼在一起。

镜头先解决遮挡、转向惯性、距离和晕动舒适性，再添加演出。可关闭镜头晃动，字幕可调大。声音至少区分石桥、土路、水边与雨棚，人物动作有对应的近处声音。正式配音与更多表情在关键片段成立后补齐。

冶愿原 Logo 保留在开场、暂停和结尾；承载背景与尺寸统一，不持续占据主要探索画面。

## 制作顺序与通过条件

| 阶段 | 明确交付 | 进入下一步的条件 |
|---|---|---|
| A：视觉与操控样板 | 一段可走的石桥—田边路径，两位角色和一次共同动作，晴天与雨后两个状态 | 静帧构图、近景人物、行走与镜头均可接受；在记录了型号的目标设备上测性能 |
| B：5 分钟探索开场 | 两条可选发现路径，一次取样或工具操作，一次自然的 AI 求助机会 | 首次玩家能自由发现问题，偏离主路仍有回应；不依赖制作人员口头解释 |
| C：完整的一季 | 小范围试验、变化中的等待、雨后调整、收获与饭桌收束 | 关键操作和结果可追溯，多种选择可走通，角色能回应玩家经历 |
| D：学生试玩修订 | 首轮 6–8 人的探索性观察与修改记录 | 能判断问题出在操作、动机、理解还是美术；扩大样本前完成主要修订 |

先沿用当前浏览器技术完成样板评估，观察正式角色与场景资源的加载、动画和帧率。引擎取舍在样板证据基础上决定。此方案不预设采购服务、付费资产或模型调用费用。

保留：故事设定、移动交互原型、存档与手记导出、已有测试作为基线。

重做：单线任务引导、固定读数与收成映射、重复长椅等待、NPC 行为、正式美术与关键演出。

建议将线索发现、世界状态、研究记录和人物记忆从单一阶段中拆开。章节节点控制时间和关键演出；独立状态记录玩家做过什么、知道什么，以及田地发生了什么。新存档应有明确版本与迁移或重开入口。

## 衡量“更好玩”的方式

以下为待验证的设计目标，不是当前成绩：

- 开场 15 秒内获得控制；第一分钟内有一次由玩家发起、能看见回应的行动。
- 前 5 分钟至少存在两个可自行发现的互动点；关掉精确指路后仍能大致辨认目的地。
- 首轮试玩中，至少约四分之三玩家无需口头提示就能发现长势差异，并说明自己想先查什么。小样本只用于定位问题，不作学习效果证明。
- 玩家能用自己的话说出一个选择依据和一个仍不确定的问题；评价不依赖是否得到最高产量。
- AI 使用记录能显示玩家提出了什么、附了哪些证据、如何采纳或拒绝建议；不以点击次数作为学习成效。
- 记录主动偏离路线、主动回看田地、重复查看线索和求助时机。结束后询问最想继续做的事，并结合行为观察判断探索动机。
- 视觉验收使用实际游戏截图和实时操作，分别检查远景、人物近景和雨后近景。概念图不能代替运行画面。
- 性能目标暂定：指定目标电脑 1080p 常规探索达到 60 FPS，入门设备降档后稳定 30 FPS；必须记录设备、加载时间、帧时间分布与异常停顿，不能只报平均帧率。
- 功能验收增加：线索发现顺序变化、比较条件不齐、试验混合多个处理、AI 拒绝建议、雨后改计划、不同阶段重载、触屏交互和镜头遮挡。

本轮完成的是方案研究与源码评审。v0.2 游戏未按此方案改造，以上升级均需逐项制作和验收。
